## Notifications — speak when a task finishes
- **At the end of every tool-using turn, write ONE short Turkish line — topic + task-type — to `~/.claude/hooks/.turn-summary`** describing what you just did. Pick the verb by type: a question → `«konu» sorusu cevaplandı`; research/investigation → `«konu» araştırması tamamlandı`; debugging → `«konu» debug edildi`; planning → `«konu» planlaması tamamlandı`; code / changes / an operation performed → `«konu» tamamlandı`. Keep it ≤ ~12 words, plain text (no markdown). A **Stop hook** (`notify-task-done.sh`) speaks it via **edge-tts** (voice `tr-TR-AhmetNeural`) and deletes it; if you forgot to write it, it falls back to "«conversation auto-title» tamamlandı". Plain (no-tool) chat replies stay silent.
- A **long-task interim announcer** — a UserPromptSubmit hook (`interim-start.sh`) spawns `interim-notify.sh`, which the Stop hook kills at turn end — speaks "«topic» hala çalışıyor, şu an …" every ~10 min while a turn is still running. All of this is **hooks** (zero token); the only thing you actively do each turn is write the one-line `.turn-summary`.
