## Form inputs — errors only under an input
- When designing or building a form, never put text under an input — no helper, hint, description or tooltip copy beneath a field.
- The space under an input is reserved **only** for that field's validation error message, shown solely while the field is in an error state; when there is no error it stays empty.
- Never write long explanations into a placeholder — keep it to a short example value or leave it empty. Keep the label above the input clean, too.
