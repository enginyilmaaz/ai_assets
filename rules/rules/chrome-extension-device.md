## Chrome extension — drive the browser on this computer, never another machine
- The Claude in Chrome extension connects **every** Chrome signed into the same account, on every machine that has it installed. Browser actions go to whichever of them the session is pointed at, so without a deliberate choice a tab can open on another computer's screen while nothing happens on this one.
- **Call `list_connected_browsers` before the first browser action of a session.** When more than one browser comes back, do not accept the default: it is only *the browser picked last* — account state, not a statement about this machine.
- **Pick by evidence, in this order.** (1) `onThisComputer: true`, when exactly one entry has it. (2) Otherwise the entry whose `name` equals this machine's host name (`hostname`, `hostnamectl --pretty`, `$env:COMPUTERNAME`) — an exact match is this computer. Then `select_browser` with that `deviceId`.
- **`isLocal` is not that evidence.** It only says the operating system matches, so on an account with several machines on the same OS it is true for all of them. A display name that is not the host name proves nothing either, and `onThisComputer` is frequently absent altogether — treat its absence as *unknown*, never as *no*.
- **When nothing matches, ask** (`AskUserQuestion`, candidates from this computer first, `deviceId` in the label) instead of guessing. Never pick one silently.
- **A tab that did not appear on this screen means the wrong browser.** Stop, list again, select again — do not keep driving a browser somebody else is looking at.
