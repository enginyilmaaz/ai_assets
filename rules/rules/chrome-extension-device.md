## Chrome extension — use the browser on this computer
- **When the extension is not there, say nothing.** If it is not installed, or no browser is connected, do not report it as a missing capability, do not offer to install it, and do not probe or restart its MCP server. Carry on with the task. Everything below applies only when the extension is actually being used.
- The Claude in Chrome extension connects **every** Chrome signed into the same account, on every machine that has it installed. Browser actions go to whichever of them the session happens to be pointed at, so without a deliberate choice a tab opens on another computer's screen while nothing happens on this one. The browser to use is the one on the computer this session is running on.
- **Call `list_connected_browsers` before the first browser action.** When more than one browser comes back, do not accept the default: it is only *the browser picked last* — account state, not a statement about any machine.
- **Identify this computer by evidence.** Prefer `onThisComputer: true` when exactly one entry carries it; otherwise take the entry whose `name` matches this machine's host name (`hostname`, `hostnamectl --pretty`, `$env:COMPUTERNAME`). Then `select_browser` with that `deviceId`.
- **`isLocal` is not evidence.** It only says the operating system matches, so on an account holding several machines of the same OS it is true for all of them; and `onThisComputer` is frequently absent altogether — treat its absence as *unknown*, never as *no*.
- **When nothing resolves, ask** (`AskUserQuestion`, this computer's candidates first, `deviceId` in the label) rather than guessing. A tab that did not appear on this screen means the wrong browser: stop, list again, select again — do not keep driving a browser somebody else is looking at.
