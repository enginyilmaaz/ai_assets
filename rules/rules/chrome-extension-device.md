## Chrome extension — drive the browser on the machine you mean
- The Claude in Chrome extension connects **every** Chrome signed into the same account, on every machine that has it installed. Browser actions go to whichever of them the session is pointed at, so without a deliberate choice a tab can open on another computer's screen while nothing happens on this one.
- **Call `list_connected_browsers` before the first browser action of a session.** When more than one browser comes back, do not accept the default: it is only *the browser picked last* — account state, not a statement about any machine.
- **The target is this computer, unless the user names another machine.** Resolve it by evidence, in this order: (1) `onThisComputer: true`, when exactly one entry has it; (2) otherwise the entry whose `name` matches this machine's host name (`hostname`, `hostnamectl --pretty`, `$env:COMPUTERNAME`). Then `select_browser` with that `deviceId`.
- **A machine the user names is the target, and reaching it is the point.** Working on a remote machine from here is a deliberate act, not a mistake to be prevented. Resolve the name against the connected browsers and against the machines this computer already knows — the `Host` aliases in `~/.ssh/config` — then select that browser and **say which machine you are driving before the first action**, because the window opens on a screen you cannot see.
- **Match names normally, not literally.** Fold case, ignore separators, and ignore a trailing machine-type suffix such as `-pc`, `-win`, `-laptop`: an alias `office-linux` and a browser named `OFFICE-LINUX-PC` are the same machine. An exact match is the exception, not the rule.
- **An SSH alias is not a browser.** It tells you the machine exists and what it is called here; it says nothing about the extension being connected there. When a named machine has no connected browser, say so and list what is connected — never silently fall back to another machine.
- **`isLocal` is not evidence.** It only says the operating system matches, so on an account with several machines of the same OS it is true for all of them; and `onThisComputer` is frequently absent altogether — treat its absence as *unknown*, never as *no*.
- **When nothing resolves, ask** (`AskUserQuestion`, candidates from this computer first, `deviceId` in the label) instead of guessing, and never pick one silently. A tab that did not appear where you expected means the wrong browser: stop, list again, select again.
